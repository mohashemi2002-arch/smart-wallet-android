# Development & Patching Utilities (`scripts/`)

This directory houses development automation, database seeding, UI patching, and maintenance scripts used during development cycles of Smart Wallet Android.

## Contents
- **Python Automation Scripts (`*.py`)**: Helper utilities for bulk refactoring, string transformations, regex debugging, and sample JSON/Excel data dumping.
- **Git Patch Files (`*.patch`)**: Incremental feature patches, bugfix diffs, and exploratory change snapshots.
- **Shell Scripts (`*.sh`)**: Asset downloads and local batch execution helpers.

> **Note**: None of these scripts are packaged into the production Android APK or bundle.
